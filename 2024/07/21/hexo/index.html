hexo+github博客搭建

分类： 搭建博客
标签： hexo

日期：2024-07-21 15:40:55

#1.前期准备

nodejs国内源

[git环境安装](Git for Windows)

#2.注册github

github官网

2.注册完成之后进入主页面，点击右上角选择创建新仓库

填写仓库名即可

3.然后在本地磁盘创建一个空的文件夹进入里面

4.在搜索框里面输入cmd，并回车，进入命令行模式

5.复制一下几行命令初始化hexo

检测npm和git否安装成功

成功样式

（1）安装hexo，注意我将npm更改为了cnpm所以是cnpm进行安装

出现如下图则代表成功

浏览器访问 http://localhost:4000/ 出现下图说明启动成功

#3.更换主题

[hexo主题官网](Themes | Hexo)

将其下载至博客文件夹下的themes目录下，接下来将博客文件夹下的_config.yml文件里面的theme:后面的更改为下载的主题包的名称

例如我的

接着将主题里面的_config.yml文件复制到桌面上在重命名为_config.cola.yml在将重命名的文件复制到博客问价目录下

后面更改配置主题里面的_config.yml和博客目录下的_config.cola.yml需要一起修改成一样的（注可以直接复制粘贴，这样只需要敲一次）

2.换完主题可以在本地看一下

浏览器访问 http://localhost:4000/ 出现下图说明主题启动成功，（主题不一样看到的不一样）

#4.部署到github上面

新建仓库的设置

接着在博客目录下的_config.yml，拉到最后，填写deploy模块：repository 填写刚才复制的链接

绑定github

*在GitHub主页的头像下找到seething*

*然后点击SSH and GPG keys，点击New SSH key*

*将刚刚在.ssh目录下所复制的id_rsa.put文件中的信息复制进key(注意空格)（名字随意）*

*输入命令（git）：**ssh -T git@github.com 并且输入yes之后，行末尾会显示你的用户名***

（绑定成功邮箱会收到邮件提醒）

*接着在本地绑定与Github的用户名和邮箱（git）*
*输入命令：**git config –global user.name “注册时用户名”***
*输入命令：**git config –global user.email “注册时邮箱”***

一定要安装 Git 插件：

执行成功可以通过 你的用户名.github.io 来访问博客了。

至此搭建博客并部署已全部完成。
